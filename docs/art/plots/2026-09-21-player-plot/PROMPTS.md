# Player plot design concepts

Generated using the built-in imagegen tool on 2026-09-21. Visual review mockups only; game code has not been changed.

## Review notes

1. **Garden Workshop** — warm timber, sage metal, planting and a cozy personal workshop.
2. **Pocket Power Town** — cheerful utility-yard architecture and small municipal landmarks; strongest connection to the creature-powered city premise.
3. **Containment Campus** — rounded white laboratory architecture and strong element-colored socket readability.

These are art-direction images, not construction plans. The existing game uses a 60×60-stud plot with 24 pads in a 6×4 grid, six initially unlocked. Generated pad counts and machine placement are illustrative (Garden Workshop compresses the grid to three rows). Any implementation must retain all 24 pads and space each machine behind its creature within that station. Circuit lines in these concepts illustrate the visual treatment, not valid recipe pairings: the game permits compatible adjacent pairs, with each creature in only one pair. Creature appearances, additional signs, and proposed decorative assets are illustrative.
